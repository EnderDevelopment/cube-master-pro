# Rubik's Cube Game

This project contains scripts for a Rubik's Cube game with enhanced features. It includes server-side and client-side scripts to create and interact with a Rubik's Cube in Roblox. The server script handles the creation of the cube and player interactions, while the client script manages player input and communication with the server.

## Install

1. Open Roblox Studio.
2. Create a new place.
3. Create a new folder in ServerScriptService and name it "RubiksCubeGame".
4. Create a new script in the "RubiksCubeGame" folder and name it "RubiksCubeGame.server.lua".
5. Copy the contents of the "RubiksCubeGame.server.lua" file from this project into the script.
6. Create a new folder in StarterPlayerScripts and name it "RubiksCubeClient".
7. Create a new script in the "RubiksCubeClient" folder and name it "RubiksCubeClient.client.lua".
8. Copy the contents of the "RubiksCubeClient.client.lua" file from this project into the script.
9. Save and play the game in Roblox Studio.

## Use

1. Launch the game in Roblox Studio.
2. Players can interact with the Rubik's Cube by clicking on its pieces.
3. The server will handle the rotation of the cube pieces based on the player's interactions.
